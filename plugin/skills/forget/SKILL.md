# 메모 삭제

사용자가 지우려는 것: $ARGUMENTS

삭제는 이 사용자의 모든 세션과 에이전트에 영향을 주므로, 어느 메모인지 사용자가 확인한 뒤에 지운다.

**방금 한 저장이나 삭제를 되돌리는 경우** (`last`, "방금 거", "취소"): conntext MCP 서버의 `forget` 도구를 `undo_last: true`로 호출하고 결과를 알린다.

**메모 id가 주어진 경우** (`m:42`처럼): `get_memos`로 내용을 가져와 보여 주고, 맞는지 확인받은 뒤 `forget`에 `memo_id`로 호출한다.

**내용으로 지정한 경우**: `forget`에 `query`만 넣어 호출한다. 이때는 아무것도 지워지지 않고 후보 목록이 온다. 후보를 번호와 함께 보여 주고 어느 것인지 묻는다. 사용자가 고르면 `memo_id`로 다시 호출한다. 후보가 하나뿐이어도 내용을 보여 주고 확인받는다.

삭제한 뒤에는 결과 문구를 그대로 보여 준다. 지운 메모가 이전 메모를 대체하던 것이었다면 이전 메모가 다시 유효해지는데, 그 사실이 결과 문구에 나온다. 삭제는 7일 안에는 되돌릴 수 있다고 알려 준다.

내용이 틀려서 지우려는 것이라면, 지우는 대신 바른 내용으로 고치는 편이 나은지 한 번 묻는다. 고치면 이전 내용이 "대체됨"으로 남아 변경 이력이 보인다. 고칠 때는 `remember`에 `replaces`로 그 메모 id를 넣는다.

팀 공간의 메모는 본인이 올린 것만 지울 수 있다. 다른 사람이 올린 팀 메모가 틀렸다면 웹의 팀 공간에서 신고할 수 있다고 안내한다.
