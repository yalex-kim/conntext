# 메모 저장

사용자가 저장하려는 내용: $ARGUMENTS

Conntext는 이 사용자가 여러 세션과 에이전트에 걸쳐 쓰는 메모 공간이다. 여기에 저장한 내용은 종류에 따라 다음 세션에 자동으로 들어가거나 검색으로 꺼내진다. 사용자가 직접 승인한 내용만 들어가야 믿고 쓸 수 있으므로, 저장은 사용자가 원한 것만 한다.

## 내용이 주어졌을 때

conntext MCP 서버의 `remember` 도구를 한 번 호출한다.

- `text`에는 사용자가 쓴 표현을 그대로 넣는다. 요약하거나 다듬지 않는다. 분류와 정리는 서버가 하고, 원문은 나중에 사용자가 다시 읽는다.
- 내용에 `--global`이 있으면 그 표시를 빼고 `scope: "global"`로 저장한다. 그 외에는 scope를 넣지 않는다. 서버가 현재 저장소 범위로 저장한다.
- 사용자가 방금 조회한 기존 메모가 틀렸다며 바로잡는 경우에는 `replaces`에 그 메모의 id를 넣는다. 그러면 이전 메모가 "대체됨"으로 남고 새 내용이 적용된다. `replaces`는 사용자 자신의 메모(recall 결과의 [내 메모], [세션 자동 추출·미확인])에만 쓴다. 팀 지식은 다른 공간에 있어 대체되지 않는다.

도구가 돌려준 결과 문구를 사용자에게 그대로 보여 준다.

결과에 "항상 적용 지시·선호가 상한을 넘었습니다"가 있으면, 함께 온 지시 목록을 보고 정리안을 한두 개 제안한다. 지시·선호는 모든 세션에 항상 들어가므로 작고 겹치지 않게 유지해야 하고, 넘친 만큼은 오래된 것부터 빠진다.

- 같은 대상에 대한 지시가 여럿이면 한 문장으로 합친다. 예: "커밋 메시지는 영어로" + "커밋 메시지는 명령형으로" → "커밋 메시지는 영어 명령형으로 쓴다".
- 이유나 예시가 길게 붙은 지시는 규칙만 남겨 줄인다.
- 더 이상 맞지 않는 지시는 지우자고 한다.

제안만 하고, 사용자가 고른 것만 실행한다. 사람이 승인하지 않은 변경은 에이전트의 기본 동작을 바꾸면 안 되기 때문이다. 합칠 때는 합친 문장을 `remember`에 `replaces`로 그중 하나의 id를 넣어 저장하고, 나머지는 `forget`에 `memo_id`로 지운다. 줄일 때는 줄인 문장을 `replaces`로 저장한다. 원문은 이력에 남는다. 어느 주제 문서에 들어갔는지, 이전 메모를 대체했는지가 거기 적혀 있고, 사용자는 이 한 줄로 저장이 의도대로 됐는지 확인한다. 분류가 틀렸다고 하면 `forget` 도구에 `undo_last: true`로 되돌릴 수 있다고 알려 준다.

## 내용 없이 불렸을 때

이번 세션에서 남길 만한 것을 골라 제안한다. 다음 세션의 에이전트가 모르면 같은 시행착오를 반복할 내용이 기준이다.

- 내린 결정과 그 이유
- 찾아낸 원인
- 이 저장소의 규칙이나 함정
- 사용자가 밝힌 선호

코드를 읽으면 알 수 있는 것이나 이번 작업에만 해당하는 세부는 넣지 않는다. 후보는 세션을 보지 않은 사람도 이해할 수 있는 독립된 문장으로, 많아야 다섯 개까지 정한다. 남길 만한 것이 없으면 없다고 말하고 끝낸다.

### 기존 메모와 견주기

후보를 보여 주기 전에, 이미 저장된 내용과 겹치거나 어긋나는지 확인한다. 사용자가 이미 아는 내용을 다시 고르게 하지 않고, 동료가 적어 둔 것이면 그 사실을 알려 주기 위해서다.

후보들의 핵심 단어(시스템 이름, 설정값의 대상, 결정의 주제)를 한 줄로 묶어 `recall`을 **한 번만** 호출한다. `limit`은 10으로 한다. 후보마다 따로 찾지 않는다. 호출이 늘면 그만큼 사용자가 기다린다.

결과를 후보마다 견줘 셋 중 하나로 정한다.

- **이미 있음**: 같은 사실이 이미 있다. 표현만 다른 것도 포함한다. 후보에서 빼고, 목록 아래에 "이미 있음: m:번호 (한 줄 요약)"으로 알린다. [팀 지식]이면 작성자도 적는다.
- **어긋남**: 같은 대상에 대해 값이나 결정이 다르다("배포는 금요일" ↔ "배포는 목요일"). 후보에 남기고 어느 메모와 어긋나는지 표시한다.
  - 그 메모가 [내 메모]나 [세션 자동 추출·미확인]이면 "m:번호를 고침"으로 표시한다. 사용자가 이 후보를 고르면 `replaces`에 그 id를 넣어 저장한다.
  - 그 메모가 [팀 지식]이면 "팀 지식 m:번호(작성자)와 다름"으로 표시한다. 고르면 `replaces` 없이 내 메모로 저장하고, 팀 지식은 그대로 남는다고 알린다. 팀 지식이 틀렸다면 웹의 팀 공간에서 신고하거나 작성자에게 알리라고 한 줄 덧붙인다.
- **새것**: 관련 메모가 없거나, 같은 주제에 정보를 더하는 것이다. 그대로 둔다.

판단이 서지 않으면 "새것"으로 둔다. 겹친다고 잘못 빼면 사용자가 그 후보를 볼 기회를 잃는다. [진행 상태] 결과는 견주지 않는다.

### 보여 주기와 저장

남은 후보에 번호를 붙여 보여 주고, 어긋남 표시는 후보 끝에 붙인다. 이미 있어서 뺀 것은 그 아래에 따로 적는다. 후보가 하나도 남지 않으면 그렇다고 말하고 끝낸다.

사용자가 고른 것만 `remember`로 하나씩 저장하고, 결과 문구를 모아 보여 준다. 사용자가 고르기 전에는 아무것도 저장하지 않는다. 이 과정에서 견줘 보려고 꺼낸 메모는 답에 쓴 것이 아니므로 `mark_used`를 호출하지 않는다.
