# 참고 영상 분석: 김플립 「pstack 제대로 파헤쳐 보기」 (24분)

https://youtu.be/u2oDdU6z4Bw · 장면 전환점 240곳, 대표 화면 155장, 전환 구간 0.5초 간격, 자동 자막으로 분석했다.
가져올 것은 **설명 기법**이다. 그 영상의 그림·캐릭터(감자 마스코트 등)는 쓰지 않고, 같은 원리로 Conntext의 세계를 만든다.

## 1. 무엇이 설명을 받쳐 주나

### 화면 세계가 넷으로 나뉘고, 세계마다 맡은 일이 다르다
| 세계 | 맡는 일 | 모습 |
|---|---|---|
| **스케치북 비유** | 개념·원리 | 위에 스프링이 달린 크림색 종이, 별 낙서, 손그림 막대 인물과 AI 로봇(가슴에 "AI" 배지), 마스킹테이프·종이 태그에 손글씨 라벨 |
| **증거 카드** | "정말 그렇게 적혀 있다" | 밝은 회색 바탕에 브라우저 창 틀로 원문(README, 발표 슬라이드)을 띄우고, 핵심 구절에 형광펜, 아래 작은 "번역" 칩, 왼쪽 아래 출처 칩 |
| **실제 시연** | "실제로 이렇게 된다" | 터미널(Claude Code) 녹화, 오른쪽 위에 단계 표시("3단계 · 기능 추가" + 진행 점), 비교는 나란히 두 창 |
| **진행자 얼굴** | 의견·강조·주의 | 얼굴 화면 + 오른쪽에 굵은 글씨 패널(형광 강조) |

세계 사이는 그냥 자른다(하드 컷). 그래서 시청자는 "지금은 비유", "지금은 증거"를 화면만 보고 안다.

### 비유 하나가 원리 하나를 맡는다
- 딥다이브 → 땅을 파서 빛나는 것을 찾는 사람. 회사 흉내 내는 스킬 → 모자 쓴 역할 캐릭터들의 조직도. 작업 순서 → 레시피 카드. 하네스 5층 → 선반 다섯 층이 각각 빨간 '버그' 얼룩을 막는 건물. 자동화 → 깔때기와 나팔이 달린 기계. 안 쓰는 도구 → 바닥에 놓인 연장통.
- 문제는 늘 같은 기호(빨간 별 모양 얼룩)로 보여 주고, 해결은 그 얼룩이 막히는 장면으로 보여 준다.

### 나레이션 단어에 맞춰 그림이 한 조각씩 생긴다 (전환 구간 0.5초 분석)
"1층 코드베이스와 아키텍처, 나쁜 패턴을 아예 못 쓰게 만든다" 구간:
1. 1층 선반이 그려져 있고 라벨 `codebase`가 붙는다 → 손글씨 한국어 풀이("코드베이스 · 아키텍처")가 아래에 써진다.
2. 카메라가 오른쪽으로 다가가고, 빨간 얼룩이 날아와 선반 벽에 막힌다("못 쓰게 만든다"에 맞춰).
3. 카메라가 아래로 내려가 2층. 라벨 `static anal…`이 글자 단위로 써지고(`static analysis`), `lint`·`compiler`·`ci` 장치에 얼룩이 걸린다.
4. 3층 `rules / bugbot`, 돋보기 든 로봇이 얼룩을 잡는다. 4·5층은 빈 판에 라벨만.
5. 마지막에 **카메라가 뒤로 빠지며 다섯 층 전체**가 한 화면에 보인다(정리).

즉 ① 한 화면 안에서 카메라가 이동하며 다음 요소로 넘어가고 ② 요소는 말하는 순간에 그려지며 ③ 마지막에 전체를 보여 준다.

### 자막
아래 중앙, 어두운 반투명 상자에 흰 글씨. **문장마다 핵심어 하나가 색(연보라)으로** 바뀐다. 장 단위 진행 표시가 오른쪽 위에 있다.

### 나레이션 말투
- 묻고 답한다: "이게 정확히 뭘까요?" → "실체는 긴 MD 파일 하나입니다."
- 셋으로 센다: "첫 번째로 라우터… 두 번째로 규칙… 세 번째로 답변 규칙." 셀 때마다 화면 조각이 하나씩 생긴다.
- 비유로 바꿔 말한다: "플레이북은 작업 종류별 레시피 카드인 거죠."
- 추상 뒤에 바로 구체 예: "AI가 '아마 이게 원인입니다'랑 '로그로 확인한 원인입니다'를 구분해서 말하게."
- 정직한 단서: "물론 둘 다 본인 주장이긴 합니다."
- 한마디 정리: "한마디로, AI는 코드베이스에 보이는 걸 따라서 합니다."
- 문장이 짧다. 한 문장에 한 가지.

## 2. 따라 할 수 있나

| 기법 | 가능 여부 | 방법 |
|---|---|---|
| 스케치북 바탕·손그림 선 | 가능 | Remotion에서 SVG + rough.js(손그림 선, MIT). 종이 결은 잡음 텍스처, 위쪽 스프링은 SVG |
| 손글씨 라벨 | 가능 | 한글 손글씨 글꼴(나눔손글씨 펜·개구 등 OFL)을 앱에 넣고, 글자 단위로 써지는 애니메이션 |
| 막대 인물·로봇 | 가능 | SVG로 직접 그림. 표정·팔 동작 정도는 코드로 |
| 복잡한 손그림 물체(기계·건물) | 부분 가능 | 단순한 것은 rough.js로 직접. 복잡한 것은 이미지 API로 같은 화풍의 그림을 만들어 배경으로 쓰고, 움직이는 부분(라벨·얼룩·화살표)은 SVG로 위에 얹는다 |
| 그려지는 애니메이션 | 가능 | 선 길이(stroke-dashoffset), 글자 단위 등장, 나레이션 문장 시각(cues)에 맞춤 — bluetoothbook에서 이미 쓰는 방식 |
| 카메라 이동·뒤로 빠지며 전체 보기 | 가능 | 큰 캔버스에 장면을 그려 두고 이동·확대를 보간 |
| 증거 카드(원문 + 형광펜 + 번역 칩) | 가능 | Conntext의 실제 웹 화면을 Playwright로 찍어 브라우저 틀에 넣고, 형광펜은 위에 얹는다 |
| 터미널 시연 + 단계 표시 | 가능 | 데모 데이터로 터미널을 컴포넌트로 재현(글자가 쳐지고 결과가 찍힘). 실제 녹화보다 깔끔하고 다시 만들기 쉽다 |
| 진행자 얼굴 | 대신함 | 진행자가 없으니 쓰지 않는다. 의견·강조는 Conntext 라벨 태그 캐릭터(아이콘 A의 노란 태그에 눈)를 진행자 대신 쓸 수 있다(선택) |
| 핵심어 색 자막 | 가능 | `caption`에 핵심어 표시(`**목요일**`)를 두고, 브랜드 노란색 형광펜으로 |
| 말투 | 가능 | 대본을 위 원칙으로 다시 쓴다 |

## 3. Conntext에 맞추면

- **세계**: 스케치북 + Conntext의 노란 케이블 라벨. 손글씨 라벨을 노란 태그(conn- 라벨 모양)로 붙이면 브랜드와 자연스럽게 이어진다. 형광펜·핵심어도 브랜드 노란색.
- **반복 기호**: 문제는 "흩어져 날아가는 메모지"(세션이 바뀌면 사라지는 기억), 해결은 "노란 라벨이 붙어 제자리에 꽂히는 메모".
- **증거 카드**: Conntext 웹 화면(위키 근거 번호, 에이전트 화면의 예산 막대, 메모의 대체 이력)을 실제로 찍어 쓴다.
- **시연**: 터미널 재현(`/remember` 결과 줄, 세션 시작 블록, `/resume`).

### 장면별 비유 (PLAN.md의 장면에 대응)
| 장면 | 비유 | 증거/시연 |
|---|---|---|
| S1 훅 | 책상 앞 개발자와 AI 로봇. 개발자가 메모지 세 장을 건네지만 세션이 끝나면 메모지가 바람에 흩어진다. 다음 날 똑같은 메모지를 다시 쓴다 | 터미널: 에이전트가 `pytest`를 직접 불러 실패 |
| S2 브랜드 | 흩어진 메모지에 노란 라벨이 붙으며 `conntext`, `nn`이 라벨 아이콘이 된다 | — |
| S3 적기 | 메모지가 분류기를 지나 네 칸 서랍(지시·선호/지식/절차/진행 상태)에 꽂힌다. 같은 칸의 화요일 메모에는 줄이 그어지고 '이력' 철에 들어간다 | 터미널: `/remember` 결과 줄 → 웹: 메모의 대체 이력 |
| S4 세션 시작 | 출근하는 로봇의 가방을 챙겨 준다. 가방 옆에 무게 눈금(예산)이 있고, 칸마다 지시·진행 상태·목록이 들어간다. 무거운 본문은 사물함에 두고 열쇠 번호만 넣는다 | 웹: 에이전트 화면의 예산 막대 |
| S5 절차 | 색인 탭이 달린 카드 상자. 탭에는 '언제 쓰는지'만 보인다. "게이트웨이 재시작"을 듣는 순간 로봇이 맞는 탭을 뽑아 순서대로 체크 | 웹: 절차 문서 |
| S6 이어받기 | 이어달리기. 클로드 코드 로봇이 바통(진행 상태 카드)을 오픈코드 로봇에게 넘긴다. 트랙에 열 걸음마다 깃발(체크포인트) | 터미널: `/resume` 결과 |
| S7 신뢰 | 연필로 쓴 메모(점선, 미확인)와 펜으로 쓴 메모(실선). 사람이 확인하면 펜으로 덧쓴다. 연필 메모는 가방에 넣지 않는다 | 웹: 홈의 후보 확인 버튼 |
| S8 팀 | 노트(위키) 문장 끝에 각주 번호, 번호를 따라가면 원래 메모지. 쓸 만한 메모를 팀 게시판에 핀으로 꽂고, 동료의 로봇이 이름표와 함께 읽는다 | 웹: 위키 근거 번호 → 원문 |
| S9 안심 | 메모가 지나가며 비밀 부분에 검은 가림띠. 운영자는 유리창 너머로 계기판만 본다. 예외 열람 상자는 깨면 사유 쪽지가 남고 주인에게 종이 울린다 | 웹: 운영 화면(지표만) |
| S10 정리 | 카메라가 뒤로 빠지며 지금까지의 비유가 한 페이지(스케치북 펼침)에 모두 보인다. 책상으로 돌아와 로봇이 한 번에 통과 | — |

### 나레이션도 이 말투로 다시 쓴다
- 장면마다 "묻기 → 답 → 비유 → 구체 예" 중 둘 이상.
- 셀 때(지시·지식·절차·진행 상태)는 하나씩 말하고, 화면도 하나씩 생긴다.
- 한 문장에 한 가지. 지금 초안의 긴 문장(S7, S9)은 나눈다.
