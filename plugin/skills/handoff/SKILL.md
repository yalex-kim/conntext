# 진행 상태 넘기기

사용자가 덧붙인 말: $ARGUMENTS

이 세션에서 한 일을 돌아보고, 이어받는 쪽이 이 대화를 보지 않고도 바로 시작할 수 있는 진행 상태를 쓴다. 읽는 쪽은 다른 날의 이 사용자이거나 다른 플랫폼의 에이전트이고, 이 세션의 대화는 볼 수 없다.

다음 순서로 쓴다.

```
요청: 사용자가 이 세션에서 하려던 일 한 줄
완료: 끝낸 일. 바꾼 파일과 확인한 방법(돌린 테스트, 결과)
남은 일: 아직 안 한 일. 어디를 보면 되는지 파일과 식별자를 넣어서
주의: 시도했다가 안 된 방법, 아직 확인하지 못한 가정, 건드리면 안 되는 것
```

- 실제로 한 일만 "완료"에 쓴다. 테스트를 돌리지 않았으면 돌리지 않았다고 쓴다.
- "남은 일"은 다음 사람이 그대로 시작할 수 있을 만큼 구체적으로 쓴다. "마무리 필요"가 아니라 "broker/acl_cache.py의 TTL이 토큰 갱신 주기보다 긴지 확인".
- 사용자가 덧붙인 말이 있으면 반영한다.
- 해당 사항이 없는 줄은 뺀다.

쓴 내용을 conntext MCP 서버의 `handoff` 도구에 `text`로 넘긴다. 저장소마다 최신 진행 상태 하나만 유효하므로, 이전 상태는 자동으로 대체된다.

저장한 진행 상태와 도구의 결과 문구를 사용자에게 보여 준다. 사용자가 고칠 곳을 말하면 고쳐서 다시 `handoff`를 호출한다.

이 세션에서 나온 결정이나 원인처럼 작업이 끝난 뒤에도 쓸모 있는 내용이 있으면, 진행 상태와 별개로 `/conntext:remember`로 남길지 한 줄로 묻는다. 진행 상태는 2주 뒤 만료되지만 메모는 남는다.
