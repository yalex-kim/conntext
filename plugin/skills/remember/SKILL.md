# 메모 저장

사용자가 저장하려는 내용: $ARGUMENTS

Conntext는 이 사용자가 여러 세션과 에이전트에 걸쳐 쓰는 메모 공간이다. 여기에 저장한 내용은 종류에 따라 다음 세션에 자동으로 들어가거나 검색으로 꺼내진다. 사용자가 직접 승인한 내용만 들어가야 믿고 쓸 수 있으므로, 저장은 사용자가 원한 것만 한다.

## 내용이 주어졌을 때

conntext MCP 서버의 `remember` 도구를 한 번 호출한다.

- `text`에는 사용자가 쓴 표현을 그대로 넣는다. 요약하거나 다듬지 않는다. 분류와 정리는 서버가 하고, 원문은 나중에 사용자가 다시 읽는다.
- 내용에 `--global`이 있으면 그 표시를 빼고 `scope: "global"`로 저장한다. 그 외에는 scope를 넣지 않는다. 서버가 현재 저장소 범위로 저장한다.
- 사용자가 방금 조회한 기존 메모가 틀렸다며 바로잡는 경우에는 `replaces`에 그 메모의 id를 넣는다. 그러면 이전 메모가 "대체됨"으로 남고 새 내용이 적용된다.

도구가 돌려준 결과 문구를 사용자에게 그대로 보여 준다. 어느 주제 문서에 들어갔는지, 이전 메모를 대체했는지가 거기 적혀 있고, 사용자는 이 한 줄로 저장이 의도대로 됐는지 확인한다. 분류가 틀렸다고 하면 `forget` 도구에 `undo_last: true`로 되돌릴 수 있다고 알려 준다.

## 내용 없이 불렸을 때

이번 세션에서 남길 만한 것을 골라 제안한다. 다음 세션의 에이전트가 모르면 같은 시행착오를 반복할 내용이 기준이다.

- 내린 결정과 그 이유
- 찾아낸 원인
- 이 저장소의 규칙이나 함정
- 사용자가 밝힌 선호

코드를 읽으면 알 수 있는 것이나 이번 작업에만 해당하는 세부는 넣지 않는다. 후보는 세션을 보지 않은 사람도 이해할 수 있는 독립된 문장으로, 많아야 다섯 개까지 번호를 붙여 보여 준다. 남길 만한 것이 없으면 없다고 말한다.

사용자가 고른 것만 `remember`로 하나씩 저장하고, 결과 문구를 모아 보여 준다. 사용자가 고르기 전에는 아무것도 저장하지 않는다.
