세션을 닫으면 진행 상태가 넘어갑니다

세션이 끝나면 플러그인의 훅이 대화를 서버로 보냅니다. 서버는 도구 결과를 버리고 발화만 남긴 뒤, 끝낸 일과 남은 일을 진행 상태로 정리합니다.

원인이나 결정처럼 남길 만한 문장은 후보로 따로 둡니다. 후보는 사람이 확인하기 전까지 에이전트의 기본 동작을 바꾸지 않습니다.

팀에 공유하면 동료의 세션에도 들어갑니다

웹에서 내 메모를 팀으로 공유하면, 원본은 내 공간에 그대로 두고 출처가 붙은 복사본이 팀 공간에 생깁니다. 동료의 세션에는 팀 지식 색인으로, /recall 결과에는 작성자 이름과 함께 들어갑니다.

설치하고 첫 메모를 적어 보세요

플러그인 설치 두 줄, 토큰 발급, 연결 한 줄이면 됩니다. 설정은 ~/.conntext/config.json에 한 번 저장되고 Claude Code와 OpenCode가 함께 씁니다.

  1. Claude Code에 플러그인을 설치합니다

    터미널
    $ claude plugin marketplace add <conntext 저장소 주소>$ claude plugin install conntext@conntext

  2. 웹에서 토큰을 받습니다

    웹의 설정 > 연결에서 토큰을 발급합니다. ctx_로 시작하는 값입니다.

  3. 서버에 연결합니다

    터미널
    $ mkdir -p ~/.conntext/bin && curl -fsSL http://서버:7373/client/conntext.py -o ~/.conntext/bin/conntext.py$ python3 ~/.conntext/bin/conntext.py setup --url http://서버:7373 --token ctx_…

    OpenCode를 쓴다면 python3 ~/.conntext/bin/conntext.py install opencode를 한 번 더 실행합니다.

  4. 새 세션에서 첫 메모를 적습니다

    /conntext:remember 뒤에 다음 세션이 알았으면 하는 한 줄을 적습니다. OpenCode에서는 /remember입니다.
